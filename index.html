🐙 How to Host on GitHub Pages (Free)

1. Push to GitHub

Create a new GitHub repository named multibuzz and upload the project files.

2. Enable Pages

In your repo, go to Settings > Pages, select branch main, folder / (root), and click Save.

3. Share & Play!

Your web app will be live at https://<your-username>.github.io/multibuzz/!
